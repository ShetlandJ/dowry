Under the hood

The answer was on the page the whole time

The booking widget is TableSense. On load it makes one request for the day: every area, every 15-minute slot, every party size, with a count of tables that can actually be booked. No login, no token. We pulled it at 18:21:

GET backend.tablesense.com/booking/…/the-dowry/booking-slot-availability

{
  "bookingSlot": { "dateTime": "2026-10-15T20:00:00" },
  "options": [{
    "partySize": 2,
    "reasonId": "4a851387-…",  // Evening Food Menu
    "allTableCount": 9,
    "reservableTableCount": 0
  }, …]
}

Every slot from 18:30 to 20:30, in all six areas: nothing bookable for two. The first table opens at 20:45, under "Drinks after 9pm". The widget had all of this before the first button was pressed.

The improvement

Lead with what you can book

We built this as a small Chrome extension to prove the point. It reads the same data and shows it as one line across the top of thedowry.co.uk.

thedowry.co.uk

One glance, before any form. Tonight, for two: 20:45 to 21:15 for drinks, or a table from 21:30. No screens to go through first.

Change the party size, it updates instantly. No extra requests. The data is already in the page.

Built into the widget, it could go further

Grey out times that can't be booked. The time picker on step 1 can show which slots have a table for your party size.

Let the time choose the reason. Pick 20:45 and it's "Drinks after 9pm". There's no need to ask.

Ask about access after a slot is chosen. Each table already carries wheelchair, dog and pram flags, so the answers can narrow the result instead of coming before it.

If the night is full, say so on the first screen, with the phone number, not after three steps.

Everything it does with the response

// data = the availability response the widget already downloads
const free = {};
for (const area of data.areas)
  for (const slot of area.bookingSlots)
    for (const opt of slot.options)
      if (opt.partySize === partySize && opt.reservableTableCount > 0)
        (free[reasonName(opt.reasonId)] ??= new Set())
          .add(slot.bookingSlot.dateTime.slice(11, 16));

No new API, no backend change. The page already has this data, so it only needs to show it.
